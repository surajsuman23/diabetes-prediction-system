# Sources and data provenance

- [OpenML dataset 37](https://www.openml.org/d/37), diabetes, version 1. [Machine-readable metadata](https://www.openml.org/api/v1/json/data/37). Original owners are identified as the National Institute of Diabetes and Digestive and Kidney Diseases; the donor is Vincent Sigillito. OpenML reports the licence field as `Public`. This repository does not reinterpret that label as a specific Creative Commons licence and does not redistribute the dataset.
- Smith, J. W., Everhart, J. E., Dickson, W. C., Knowler, W. C., and Johannes, R. S. (1988). *Using the ADAP learning algorithm to forecast the onset of diabetes mellitus*. Proceedings of the Symposium on Computer Applications and Medical Care, pp. 261-265. Historical dataset reference listed by OpenML; this project does not reproduce that paper's results.
- [scikit-learn fetch_openml](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_openml.html): downloading a specific dataset by ID.
- [scikit-learn common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): data leakage and training-only preprocessing.
- [scikit-learn GridSearchCV](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GridSearchCV.html): cross-validated parameter selection.

Accessed 2026-09-22. Library and dataset ownership remains with the respective owners. No third-party implementation was copied.
